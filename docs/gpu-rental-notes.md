# 云 GPU 租用踩坑记录

> 日期：2026-10-23  
> 背景：W1 需要 A100/A800/H100 80G 跑 Qwen3.6-35B-A3B，折腾一轮**未租到**，记录备查。

## 结论先行

**35B QLoRA 最低要求 80G 显存**。2026-10-23 晚高峰时段，国内按小时租赁平台 80G 卡全线无库存；阿里云 DSW 有货但 ¥38.21/时，远超 PRD 训练预算（10–20 元）。W1 的 35B Base baseline 被迫延后，本地用 Qwen2.5-3B 先跑通 pipeline。

## 各平台实况

- 官网首页加载 15 秒，服务端不稳定
- `market/list` 筛 A100：全区域「已租完」
- 晚 7 点后是租赁高峰，热门卡全空
- **未租成**

### 优云智算（UCloud Compshare，compshare.cn）

- UCloud 旗下正规平台，官网可直连
- 地域「华北一C」只有 RTX 4090 24G（不够 35B）
- 地域「华北二A」有 80G A800 / 80G A100 / 96G H20 选项
- **结果**：A800 无库存、A100 无库存、H20 也无库存

- 另一个坑：部分主机数据盘不可扩容（容量范围 0~0GB），50GB 装不下 35B 模型
- **未租成**

- 对比：AutoDL A100 通常 ¥3–6/时，贵 6–10 倍
- 结论：可作兜底，但长期训练烧不起；适合「开 1 小时跑 spike 验证」

## 经验教训

1. **显存红线**：35B 4-bit QLoRA ≈ 20GB 底座 + optimizer/activations，**32G 卡必 OOM，只能 80G 起步**
2. **租赁时段**：晚高峰（19:00–24:00）几乎租不到热门卡；**早 6–9 点**释放最多
3. **数据盘陷阱**：租前确认数据盘可扩容，系统盘 + 数据盘 ≥ 200GB（35B 权重 60–70GB）
4. **价格锚点**：A100/A800 80G 合理价 ¥3–6/时；超过 ¥10/时只在救急时接受
5. **备用策略**：PRD 已预留 7B–8B 降配兜底条款（当前不启用）
